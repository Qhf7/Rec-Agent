# 曝光广告文案生成测试记录（2026-11-18）

本轮调整了 DeepSeek Harness 预设与 Python 批量生成客户端：由大模型从真实商品字段提炼卖点、创作广告式曝光理由，并更新对应证据和摘要。

## 测试范围与方法

- 使用 ModelGo 的 `deepseek-v4-flash`，温度 0.7，两轮各 14 条，合计 4 次真实生成请求、28 条返回；未使用人工编写文案代替模型返回。
- 覆盖抽纸、口红、炒锅、手环、大米、收纳盒、香薰、身体乳、充电宝、纸尿裤、瑜伽垫和维C共 12 类商品。
- 同一抽纸额外配给 `u_0002` 和 `u_0008`，与 `u_0001` 组成三种生活阶段，观察是否强加家庭结构。
- 商品为测试预选，用于考察文案创作，不代表这 12 个商品都适合推荐给同一用户。本次未启动新的 Harness Session，不能据此声称验证了桌面端的实际选品和新预设加载。
- 第二轮增加使用动作、包装数量、用量、证据对应和日期基准说明。两轮是问题发现与修订测试，未固定随机采样，不用于估计广告点击率或得出统计优劣结论。

## 独立检查观察

第二轮三条抽纸都没有断言用户有娃、家庭人数或纸张消耗情况。首轮的“整箱／一箱”、纸尿裤“换洗”、维C单次“嚼一片”、充电宝“不占地”、身体乳“过冬”以及口红标题证据漏列均已在第二轮输出中消失。

仍需保留的限制：大米“拆开就能下锅”可能暗示免淘洗；手环“抬腕看看”“戴全天”有轻度交互或使用体验延伸；纸尿裤“吸水也利落”扩展了吸水表现；维C“慢慢嚼”略像零食语气；收纳盒折叠与放置动作的衔接还不够顺。这些是独立编辑检查观察，不是人工金标或 Jev 判断。

本次证明新生成逻辑可运行、文案与事实可衔接，并修正了一组已观察到的问题；小样本不能证明所有输出都自然或所有事实描述都准确。用户偏好与广告效果需要更大样本和真实反馈评估。
