## 指标口径

| 指标 | 定义与证据 |
| --- | --- |
| 任务完成率 | 完成任务约束的轨迹数 / 全部尝试任务数；失败与超预算保留在分母 |
| 工具参数正确率 | 工具名、参数类型、枚举与引用对象均有效的调用数 / 全部尝试调用数 |
| 事实覆盖率 | 已实际观察且可追溯的任务所需事实数 / 任务所需事实数 |
| 平均调用数 | 所有任务中实际 Agent 模型调用、工具调用、评审调用分别统计 |
| token 消耗 | 服务返回的输入/输出/缓存用量分别保留；缺失记为未知，不能补零 |
| P95 延迟 | 完整任务和单次评审分别记录墙钟延迟，包含失败；同一并发条件比较 |

## 评审器对照规则

通用大模型和 Jev 都是评审器，评判同一批 Agent 轨迹。Agent 的执行指标由真实轨迹和可执行核验计算，评审器不直接产生工具调用或改变冻结推荐。评审器另比较有效回答率、对已知错误的识别、与程序核验的一致性、token、调用数及延迟。新增轨迹评测协议独立于线上 Jev 风险/吸引力两题，线上工作流保持现有协议。

合成场景和程序核验不等于真实用户偏好金标；离线结果不推导线上 CTR。没有实测支持的优势不写入结论。
