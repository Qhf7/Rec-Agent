# 曝光理由参考语料（300 条）

## 一句话说明

这 300 条是**参考公开样本与信息流文案句式合成编写的研究语料**。本次整理核验了下文列出的 6 条公开报道样本，300 条语料并非淘宝抓取原文。

本语料用于句式分析与研究对照，包含超过 20 字符以及带参数、促销的表达；当前生产文案需符合“不超过 20 个 Unicode 字符、不含数量或规格参数”的契约，不能直接照用本语料。

## 为什么没有抓淘宝

| 尝试 | 结果 |
| --- | --- |
| `https://www.taobao.com` 直接访问 | 返回 SEO 静态首页，只有类目导航，没有信息流 |
| `猜你喜欢` 推荐接口 | 需要登录态 Cookie 与签名参数，未登录不返回；且千人千面，无法复现同一批 |
| 抓取合规性 | 登录态个性化内容抓取违反平台协议，不适合作为项目数据来源 |
| 搜索引擎侧 | Bing 中文结果被合规过滤，只剩淘宝官网首页；DuckDuckGo 能搜到大量"猜你喜欢机制"文章，但都不含理由原文 |

## 公开可核验的真实样本（6 条）

来源：[《淘宝推荐系统的革命性升级：RecGPT 如何让购物变得更智能》](https://www.sohu.com/a/921529864_114765)（至顶头条，2025-08-07，转述 arXiv:2507.22879 的案例）。原文为杭州 30 岁女性用户案例。

| # | 真实理由 | 对应句型 |
| --- | --- | --- |
| 1 | 夏日穿搭清爽有型 | 短句并列 / 利益前置 |
| 2 | 杭州夏日氛围感上新啦 | 场景锚点 |
| 3 | 水温测量让妈妈更安心 | 商品作主语 + 称呼语 |
| 4 | 宝宝防晒这件刚刚好 | 利益前置 |
| 5 | 让外出遛娃变得轻松愉快 | 利益前置 |
| 6 | 陪伴宝宝一起享受户外时光 | 情绪氛围 |

这 6 条可对应本语料的 5 个句型，供分类参考；样本不足以验证全部 12 类划分，也不能用于推断真实分布或充当金标。

项目内另有 3 条公开报道引用的示例，见 [推荐理由曝光审核-一页纸.md](../推荐理由曝光审核-一页纸.md)；其中"杭州梅雨季防潮神器"是**违规反例**（商品无除湿功能），不要当正面样本。

## 300 条怎么来的

- 12 个句型 × 25 条 = 300，12 个类目 × 25 条 = 300，双维度均衡。
- 60 个商品各写 5 条，同一商品跨 5 种句型，便于对比"同一卖点的不同写法"。
- 按预设商品与句型合成编写，脚本保存句子并校验序号连续、文本不重复、句型与类目计数、人称与句型一致。
- 每条的 `needs_fields` 指出该句要成立需要哪些商品字段，`risk_level` 与 `note` 指出合规边界。
- `needs_fields` 是研究标记，包含早期字段名；用于当前链路前需映射到规范数据契约及审核证据白名单，不能直接作为 `evidence_fields` 传入。

## 字段

| 字段 | 含义 |
| --- | --- |
| `id` | R001–R300 |
| `text` | 理由原文 |
| `pattern` | 12 类句型之一 |
| `person` | 零人称 / 你 / 咱 / 称呼语 / 物称 |
| `category` | 12 个一级类目 |
| `product` | 商品短名 |
| `length` | 字符数（含标点） |
| `needs_fields` | 该句所需事实的研究标记，使用前映射到规范字段白名单 |
| `risk_level` | 低 / 需核验 |
| `note` | 合规边界提示或具体核验点 |

## 怎么用

1. **写提示词**：筛选符合当前生产契约的 `pattern` + `text` 作为 few-shot 候选，再验证生成效果。
2. **建评测维度**：按 `pattern` 分组统计模型的 Q2/Q3 表现，能看出模型对哪类句式最容易失守。
3. **做改写基线**：同一 `product` 的 5 条可作改写候选，按当前文案契约及商品事实筛选后再使用。
4. **补 `needs_fields`**：先映射规范字段，再与 `fact_bundle` 对表，检查客观主张是否有事实支持。

## 不要怎么用

- **不要当金标**。这批句子没有经过人工标注，正确性未验证，写进 `dev_labels.csv` 会污染评测。
- **不要声称是淘宝原文**。对外汇报时必须写明"模式语料 / 合成"。
- **不要直接上线**。其中 61 条（20.3%）含价格、参数、资质或功效表述，必须回填事实后重审。

## 复现

```bash
python3 corpus/build_corpus.py
```
